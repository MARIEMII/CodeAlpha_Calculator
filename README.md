# CodeAlpha_Calculator

A basic calculator built with HTML, CSS and JavaScript as part of the CodeAlpha Frontend Development internship (Task 2).

## Features

- Addition, subtraction, multiplication and division
- Button interface with a display screen
- Real-time result preview while you type
- Clear (AC), delete, decimal and percent
- Correct operator precedence (× and ÷ before + and −), no use of `eval()`
- Keyboard support: digits, `+ - * /`, Enter, Backspace, Esc (bonus)
- Responsive layout with light and dark mode

## How to Run

Open `index.html` in any browser.
